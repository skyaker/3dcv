# Список заданий для выполнения в классе
В папке data/city располагаются клипы. 
C использованием optical flow выполняются задачи:
- индикации характера движения "лево/право" и "стоянка/движение" (navigator.py);
- кластеризации поверхности земли (ground_from_flow_example.py);
- генерации оптического потока через нейронную сеть, например RAFT (raft_model.py);
- оптической стабилизации видео (flow_stabilize_preview.py)
- замедление видео (slow_motion.py)
